# AI Music Generation

This project is being developed as part of my CodeAlpha Artificial Intelligence Internship.

The aim is to build a music-generation model that learns patterns from MIDI files and produces a new musical sequence. The project will use Python, `music21`, and an LSTM neural network.

## Project Objective

The project will follow these main steps:

1. Collect MIDI music files for training.
2. Extract notes and chords from the MIDI files.
3. Convert the musical data into sequences suitable for model training.
4. Build and train an LSTM neural network.
5. Use the trained model to generate a new sequence of notes.
6. Convert the generated sequence into a MIDI file.

## Planned Features

- MIDI file processing
- Note and chord extraction
- Musical sequence preparation
- LSTM-based model training
- New music-sequence generation
- MIDI file export
- Training-history visualisation
